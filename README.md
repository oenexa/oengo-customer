# OENGO Customer Application (`oengo-customer`)

> **Decentralized Quick Commerce & Food Delivery Consumer Application**  
> Governed by the OENGO Product Architecture & Mobile Engineering Organizations.

## 1. Domain Ownership
This repository authoritatively owns the **Customer Commerce Experience**:
- **Capabilities**: Menu & item browsing, basket checkout, multi-rail settlement (`ONXC` or `EUR`), order live tracking, courier tipping.
- **Backend Coupling**: Interacts with `oengo-api` and `oenexa-pay` via strictly documented REST/gRPC endpoints.
